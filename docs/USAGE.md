# 生成窗口 —— 完整操作说明

**中文** · [English](USAGE.en.md)

按 `F8` 打开。需要**已经进入游戏世界**（主菜单里不行）—— 方块清单和世界边界都得有世界之后才读得到。

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 生成器 — 全部 422 种 / 当前筛选 422 件 / 第 1/27 页                        │
│ 分组: 全部   子分类: 全部（12 类）   搜索: -                              │
│ 放置: 自己选的点 (12, -4)   耐久: 100%   自动拾取: 开                     │
├───────────────────────────────────────────────────────────────────────────┤
│ ▸ [物品/医疗] 除颤器                          (defibrack)                 │
│   [植物] 天花板垂麦                           (ceilingrye)                │
│   ...                                                          （共 16 行）│
├───────────────────────────────────────────────────────────────────────────┤
│ [全部][物品][生物][植物][建筑][方块]  [搜索] [清空筛选] [键位设置] [关闭]  │
│ [◀][    子分类    ][▶][= 全部]              [重置键位][上页][下页]        │
│ [位置: 自己选的点][选点][-10%][+10%][自动拾取][全部][随5][随20][停止]     │
└───────────────────────────────────────────────────────────────────────────┘
```

> 窗口第一排的 **「键位设置」** 按钮会把这份清单换成 9 条功能键位，详见
> [README 的「键位设置」一节](../README.md#键位设置)。这里是生成窗口的说明，键位页只借用同一块区域。

## 分类

### 大分类（第一排）

| 大分类 | 里面有什么 |
|---|---|
| **全部** | 所有东西混在一起，按名字排序 |
| **物品** | 一切可捡物品，再按游戏自己的物品分类分子类 |
| **生物** | 商人、动物、怪物（`生物/商人`、`生物/动物`、`生物/怪物`） |
| **植物** | 树、蘑菇、藤蔓、苔藓、垂麦、水芦、沙玫瑰、仙人掌… |
| **建筑** | 建筑与设施，另有 `建筑/水晶`（装饰性矿物簇） |
| **方块** | 地形方块 —— 这些是**往世界里砌**的，不是掉落物 |

### 子分类（第二排）

`◀` / `▶` 在**当前大分类内**的子分类之间循环，中间按钮显示当前子分类名。
`= 全部` 一键取消子分类筛选。`Tab` 也能循环。

## 生成位置

第三排第一个按钮循环三档：

| 模式 | 按钮显示 | 生成到哪 |
|:---:|---|---|
| 0 | `位置: 角色脚下` | 你站的地方 |
| 1 | `位置: 鼠标处` | 鼠标指的世界位置 |
| **2** | **`位置: 自己选的点`** | **你手动指定的那一点**（默认） |

### 怎么选点

1. 点 **`选点`** —— 按钮变橙色，显示 `选点中…`。
2. 鼠标在世界里移动。屏幕上有一个标记点跟着走，旁边显示当前世界坐标。
3. **左键点一下**确认。提示会显示 `生成点已设为 X, Y`。
4. 之后点列表里任何一行，东西就生成在那个点上。

| 操作 | 效果 |
|---|---|
| `←` `→` `↑` `↓` | 生成点移动 1 格 |
| `Shift` + 方向键 | 移动 0.25 格（精细调整） |
| `Esc` 或 **鼠标右键** | 取消选点（生成点留在原处） |

标记点是黑框黄点，选点过程中变**红点**。只在「自己选的点」模式下显示。

> **为什么会有这个功能**：上一版只有「鼠标处 / 角色脚下」两档。而点窗口里的列表时，
> 鼠标**必然停在窗口上**，由它换算出来的世界坐标经常落在**地图外** —— 生成到地图外的
> 物体会让游戏每帧的区块/流体查询把游戏拖死。现在所有生成位置都会被夹进世界范围内，
> 生成到界外已经不可能了。

## 其它操作

| 操作 | 效果 |
|---|---|
| 左键点某一行 | 生成那一项 |
| 滚轮上/下 | 翻页 |
| 第一排按钮 | 大分类 / 搜索 / 清空筛选 / **键位设置** / 关闭 |
| 第二排按钮 | 子分类 ◀ ▶ / 全部 / **重置键位** / 上一页 / 下一页 |
| 第三排按钮 | 位置 / 选点 / 耐久 ∓10% / 自动拾取 / 生成全部 / 随机×5 / 随机×20 / 停止 |
| `↑` `↓` | 移动选中行 ※ **选点状态下**方向键改为微调生成点，要移选中行先按 `Esc` |
| `回车` | 生成选中的那一项 |
| `PageUp` `PageDown` `Home` `End` | 翻页 / 首页 / 末页 |
| `Tab` | 下一个子分类 |
| `/` | 进入/退出搜索框（直接打字筛选，`退格` 删除） |
| `Esc` | 退出搜索；再按一次关窗口 |
| `F8` | 开关窗口 |

## 键位设置页

点第一排的 **「键位设置」**，同一个窗口会换成键位页（第二排同时出现「重置键位」）：

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 键位设置 - 点一行功能，然后按下你想用的键（共 9 项）                        │
│ 左键点一行 → 按一下新键 → 立刻生效并写回配置文件                            │
│ 撞车不会拦你，但那一行会变红，末尾写「与『XXX』冲突」                        │
├───────────────────────────────────────────────────────────────────────────┤
│ ▸ 上帝模式          →   [F1]         （默认 F1）                           │
│   上天入地          →   [F2]         （默认 F2）                           │
│   ...                                                            （共 9 行）│
│   一击必杀          →   [F9]         （默认 F9）                           │
└───────────────────────────────────────────────────────────────────────────┘
（末行的「⚠ 与『XXX』冲突」只有在你真的把它们改成同一个键时才会出现）
```

| 操作 | 效果 |
|---|---|
| 左键点某一行 | 选中它，等待你按新键（该行变成 `◀ 请按下新的按键…`） |
| 按下任意键 | 立刻绑定、写回 `BepInEx\config\casualtiesunknown.godmode.cfg`、左上角状态字同步更新 |
| 等待按键时按 `Esc` | 取消这一次改键 |
| `Esc`（非等待状态） | 回到生成列表 |
| 「键位设置」按钮 | 在键位页 / 生成列表之间来回切 |
| 「重置键位」按钮 | 9 个键全部恢复默认（F1~F9） |
| `F8` 打开窗口 | 永远从生成列表开始，不会卡在键位页 |

**改键时会临时屏蔽功能热键** —— 否则你把「上帝模式」改成 `F1` 的那一瞬间就会顺手开关一次。
键位页里只有三个按钮有效：`关闭` / `键位设置` / `重置键位`。

## 数据是从哪来的

清单在运行时从三个来源组装，所以游戏加了新内容会自动出现：

| 来源 | 产出 |
|---|---|
| `Item.GlobalItems` | 全部物品 |
| `Resources.LoadAll<GameObject>("")` 里带 `Item` 或 `BuildingEntity` 组件的 prefab | 生物、植物、建筑 |
| `WorldGeneration.GetBlockInfo(ushort)` 从 0 递增探测到返回 null | 地形方块 |

生成用的是游戏自己的 `Utils.Create(id, pos, rot)` —— 和游戏内置 `spawn` 控制台命令
**完全同一条代码路径**；如果 id 不在 `Resources` 下，退回直接实例化模组手里那份 prefab。
方块走 `WorldGeneration.SetBlock`，它内部自带边界钳制。

## 名字是从哪来的

所有名字都取自游戏自己的本地化表（`Locale`）：

- 物品 → `ItemInfo.fullName`
- 生物 / 植物 / 建筑 → `Locale.GetBuilding(id)`

`BuildingEntity.fullName` **在 prefab 上是空的** —— 游戏只在实例化之后的 `Start()` 里
才填它，这就是早期版本名字显示空白的原因。

## 怎么报「分类错了」

分类是根据对象身上挂了哪些组件推断的，所以必然有个别条目会错。
保持 `DumpInventory = true`（默认），打开窗口一次就会写出：

```
<游戏根目录>\BepInEx\config\GodMode.生成物清单.log
```

每行一项，格式 `分类 | prefab名 | 身上的组件`。把这份文件附到 issue 里，我照着改规则。

## 日志

每次生成都会写一行带坐标的日志：

```
[GodMode][生成器] 已生成 ceilingrye（天花板垂麦） @ 12,-4  分类=植物
[GodMode][生成器] 开始批量生成 100 个，基准点 12,-4（位置模式=自己选的点）
```

出问题的时候，这些行能直接告诉你东西生成到哪去了。
